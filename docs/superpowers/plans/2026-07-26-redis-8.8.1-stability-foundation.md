# Redis 8.8.1 稳定性基础实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。

**目标：** 在 Cache OFF 模式下建立 Redis 8.8.1 exact Oracle、原始 RESP differential、RocksDB 权威状态机和 OpenRaft 故障证明，并用系统稳定门禁决定何时允许另立热层实现计划。

**架构：** 当前运行路径只包含 RESP/命令执行、RocksDB 权威存储和 OpenRaft 一致性链路。Redis 8.8.1 只作为兼容 Oracle 和未来接口设计基线；本计划不引入、构建、加载或发布 Redis Hot Tier Native Library。只有 `docs/quality/system-stability-gate.md` 全部通过、证据写入 `.planning/STATE.md` 且用户再次明确批准后，才能创建独立的热层实现计划。

**技术栈：** 仓库固定的 Rust 1.97.1 stable、Rust 2021 Edition、Tokio、Serde/YAML、Bytes、Clap、RESP2/RESP3、Redis 8.8.1 TCL suite、redis-rs test-only、RocksDB、OpenRaft、PowerShell、WSL/Linux、Elle/Jepsen history。
